## 写作约定

- **真实优先**：基于真实项目或真实场景。
- **失败也写**：失败案例比成功案例更有价值。
- **数据说话**：尽量给出量化数据（成本、效果、ROI）。
- **反思**：每个案例必须有"教训"部分。
