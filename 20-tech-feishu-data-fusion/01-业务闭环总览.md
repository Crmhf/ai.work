# 01 - 业务闭环总览

> **TL;DR**：企业运营有一条核心闭环——**业务数据驱动会议 → 会议产出任务 → 任务进展回写数据**。飞书生态提供了完整工具链支撑这条闭环，但**单点技术方案都不够**，需要 API + Automation + 定时补偿三层混合。

---

## 一、用户核心需求拆解

企业运营中存在一条高频且关键的业务主线：以**业务数据**为输入，通过**会议讨论**形成决策，将决策转化为**可执行任务**，并对执行进展进行**持续跟踪与检查**。

这条主线可拆解为四个紧密衔接的环节，构成一个完整的业务闭环：

### 第一环：业务数据驱动会议发起

团队在日常运营中沉淀大量数据——项目进度、客户反馈、异常告警、资源消耗等，这些数据通常以结构化形式存储在**多维表格**中。当数据触达特定阈值（如进度延迟、异常发生），需要自动或半自动地**发起会议**，召集相关人员进行讨论。

**核心诉求**：从多维表格读取数据，根据预设规则触发会议预约。

### 第二环：会议讨论产出结构化成果

会议召开后，讨论内容需要被记录并转化为可执行的信息。**飞书妙记**提供会议录制与智能纪要能力，其 AI 产物 API（`GET /minutes/v1/minutes/:token/artifacts`）可提取三大结构化输出：

- **会议纪要总结**（summary）
- **待办事项清单**（todo_list）
- **章节划分索引**（sections）

**核心诉求**：将非结构化的语音讨论转化为结构化的文字任务。

### 第三环：待办事项自动转化为跟踪任务

会议中产生的待办事项需要进入任务管理系统，被分配责任人、设定截止时间、关联优先级。**飞书任务 API（V2）**提供完整的 CRUD 能力，支持通过 `POST /task/v2/tasks` 创建任务，并通过 `origin` 字段追溯任务的会议来源。

**核心诉求**：实现"会议讨论到执行落地"的衔接。

### 第四环：任务进展回写至业务数据源

任务执行过程中的状态变更（完成、延期、阻塞）需要反馈回最初的业务数据载体（多维表格），实现进展的可视化与全局透明。

**核心限制**：多维表格 API 支持记录的读取、更新和批量操作（单次 500-1000 条），但**变更事件仅开放给 Automation Center**，外部 Bot 无法直接订阅。

**核心诉求**：进展可回写，最终一致，可靠性高。

## 三、现有手动流程的效率瓶颈

在没有系统集成的场景下，这条闭环完全依赖人工操作，存在**三个显著的效率瓶颈**：

### 瓶颈 1：信息分散与上下文丢失

业务数据、会议纪要、跟踪任务、进展反馈分散在**四个独立系统**中。参与者需反复跳转才能拼凑完整上下文。追溯"某任务来源于哪次会议"时，往往只能依赖手动维护的索引表格。

### 瓶颈 2：跟进遗漏率高

人工从会议纪要中提取待办存在显著遗漏风险。AI 提取待办事项的**准确率达 95% 以上**，但纯人工流程中待办散落在文档各处，缺乏统一收集机制。当会议数量增多（每日站会、周会、项目例会），人工跟进的可扩展性迅速触及瓶颈。

### 瓶颈 3：进展不透明与滞后

任务最新状态无法自动回写至业务数据源，管理者看到的进展存在**时间差**。人工汇总往往以天甚至周为单位，许多需即时响应的问题错过最佳处理窗口。

## 四、四个关键数据指标

完成自动化后，这四个指标会显著改善：

| 指标 | 手动流程 | 自动化后 |
|---|---|---|
| **任务落地率** | 60-70% | 提升至 85-95%（+55%） |
| **待办提取准确率** | 人工 70-80% | AI 95%+ |
| **进展更新延迟** | 1-7 天 | 5 分钟内（实时） |
| **追溯可还原度** | 30-40% | 95%+（origin 溯源） |

---

## 五、本方案覆盖范围

本方案要实现的目标：

✅ **业务数据 → 会议**：自动检测数据阈值，触发会议预约。
✅ **会议 → 任务**：妙记 AI 产物自动提取，创建任务并关联。
✅ **任务 → 业务数据**：进展变更自动回写多维表格。
✅ **可观测**：全链路 Trace 日志、监控、告警。
✅ **可靠**：Automation Webhook + 定时补偿双轨，最终一致性。

⚠️ **不覆盖**：
- 跨企业集成（仅限飞书内部生态）。
- 实时音视频分析（妙记 AI 已经做，我们只取结果）。
- 复杂业务流程建模（用任务和子任务，不上 BPM 引擎）。

---

## 六、本章关键 takeaway

- 业务闭环 = **数据 → 会议 → 任务 → 数据**，四环缺一环就是信息孤岛。
- 四个环节紧密衔接，任一断裂都会导致闭环失效。
- 自动化价值巨大：落地率 +55%、提取准确率 95%+、实时同步、可追溯。
- 飞书生态能支撑完整闭环，但**单点 API 都不够**，需要混合架构。
