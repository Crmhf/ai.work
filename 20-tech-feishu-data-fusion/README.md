# 20-tech-feishu-data-fusion — 飞书数据融合开发

> **会议纪要 → 任务 → 多维表格** 的完整闭环实现。
> 这是我做企业 AI 落地时最常用的"飞书场景"技术方案：
> 把会议讨论的结构化产出，自动变成可跟踪的任务，再把执行进展写回业务数据源。

---

## 业务闭环（一句话版）

> **数据 → 会议 → 任务 → 数据**
> 多维表格的数据触达阈值 → 自动发起会议 → 妙记 AI 提取待办 → 创建任务 → 进展回写表格。

## 适用场景

✅ **适合**：
- 项目管理（每日站会、周会、项目例会的产物自动化）
- 客户成功（客户反馈会议 → 任务 → CRM 回写）
- 异常响应（监控告警 → 应急会议 → 处置任务）
- 跨部门协同（多团队周会 → 多方任务分配）

⚠️ **需要权衡**：
- 飞书妙记是核心依赖，妙记的 AI 质量决定系统质量
- 多维表格变更事件无法直接订阅给外部 Bot（必须 Automation 桥接）
- 单租户额度限制：妙记 AI 5 QPS、任务 10 QPS

---

## 技术栈

- **运行时**：Python 3.10+
- **SDK**：飞书官方 lark-oapi SDK + OpenClaw CLI
- **存储**：多维表格（业务数据）+ Redis（去重与队列）+ 飞书任务（任务数据）
- **Web 框架**：FastAPI（Webhook 接收）
- **部署**：Docker + docker-compose
- **调度**：APScheduler（定时补偿）
