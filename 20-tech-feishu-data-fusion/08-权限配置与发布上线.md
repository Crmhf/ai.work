# 08 - 权限配置与发布上线

> **TL;DR**：飞书自建应用的权限审核是上线周期的**关键瓶颈**——涉及的所有关键 API（妙记、任务、多维表格、会议）都需要**高级权限**，审核 3-5 个工作日。**预留充足时间，提前与管理员沟通**。

---

## 一、飞书权限体系概览

飞书开放平台的权限分三级：

| 级别 | 申请方式 | 审核时长 | 示例 |
|---|---|---|---|
| **普通权限** | 应用创建后自动获得 | 立即 | 读取应用基本信息 |
| **高级权限** | 提交审核，企业管理员审批 | 3-5 工作日 | 妙记 AI、任务写、多维表格写 |
| **特殊权限** | 飞书官方单独审批 | 7-14 工作日 | 部分敏感数据 |

**本方案涉及的所有权限都是"高级权限"**，必须预留审核时间。

## 二、所需权限清单

### 必需权限

| 权限 scope | 说明 | 用途 | 审核级别 |
|---|---|---|---|
| `minutes:minutes:readonly` | 妙记只读 | 提取妙记 AI 产物 | 高级 |
| `minutes:minutes:readonly:summary` | 妙记总结只读 | 提取会议 summary | 高级 |
| `minutes:minutes:readonly:agenda` | 妙记议程只读 | 提取议程信息 | 高级 |
| `task:task:readonly` | 任务只读 | 列出任务 | 高级 |
| `task:task:write` | 任务写 | 创建/更新任务 | 高级 |
| `bitable:app` | 多维表格读写 | 操作业务数据 | 高级 |
| `bitable:app:readonly` | 多维表格只读 | 备份/对账 | 高级 |
| `vc:record:readonly` | 会议录制只读 | 获取会议信息 | 高级 |
| `vc:reserve` | 预约会议 | 创建会议 | 高级 |

## 三、权限申请步骤

### 步骤 1：在开发者后台添加权限

1. 访问 https://open.feishu.cn/app
2. 选择你的应用
3. 进入「权限管理」
4. 点击「添加权限」
5. 搜索所需 scope
6. 点击「申请」

### 步骤 2：阅读权限说明

每个权限有**详细说明**，必须阅读：

- 权限用途。
- 申请理由填写要求。
- 是否需要额外的企业配置。

### 步骤 3：填写申请理由

**示例：妙记 AI 产物权限申请理由**：

```
本应用为企业内部"会议纪要→任务跟踪"系统，需要调用妙记 AI 产物 API
（GET /minutes/v1/minutes/:token/artifacts）从会议中自动提取结构化的
纪要总结、待办事项清单和章节划分索引，用于：
1. 自动创建飞书任务，减少人工录入
2. 关联任务到会议来源，方便追溯
3. 提升会议效率与任务落地率

使用范围：仅企业内部会议，不会泄露给外部。
使用频率：约每天 50-100 次会议，符合妙记 5 QPS 限制。
```

### 步骤 4：创建应用版本

1. 进入「版本管理与发布」
2. 点击「创建版本」
3. 填写版本号（如 1.0.0）
4. 填写版本说明
5. 提交审核

### 步骤 5：等待审核

- 应用创建者会收到飞书消息通知审核结果。
- 通常 3-5 工作日。
- 紧急情况可以联系飞书技术支持加急。

## 四、tenant_access_token 管理

### 获取 token

```python
import time
import requests

class TenantTokenManager:
    """租户访问凭证管理"""
    
    def __init__(self, app_id: str, app_secret: str):
        self.app_id = app_id
        self.app_secret = app_secret
        self.token = None
        self.expires_at = 0
        self.lock = asyncio.Lock()
    
    async def get_token(self) -> str:
        """获取 token（自动刷新）"""
        async with self.lock:
            # 检查是否过期（提前 5 分钟刷新）
            if self.token and time.time() < self.expires_at - 300:
                return self.token
            
            # 申请新 token
            url = "https://open.feishu.cn/open-apis/auth/v3/tenant_access_token/internal"
            payload = {
                "app_id": self.app_id,
                "app_secret": self.app_secret
            }
            
            resp = requests.post(url, json=payload, timeout=10)
            data = resp.json()
            
            if data["code"] != 0:
                raise TokenError(f"获取 token 失败: {data['msg']}")
            
            self.token = data["tenant_access_token"]
            self.expires_at = time.time() + data["expire"]  # 通常 7200 秒（2 小时）
            
            print(f"✓ token 刷新成功，过期时间: {data['expire']}s")
            return self.token


# 全局使用
token_manager = TenantTokenManager(
    app_id="cli_xxxx",
    app_secret="secret_xxxx"
)
```

### 关键点

- token **有效期 2 小时**，必须缓存并自动刷新。
- 多实例部署时用 **Redis 集中存储**，避免重复申请。
- token 与 **app_id 绑定**，不能跨应用使用。

### 阶段 1：开发版（仅自己可见）

- 创建应用后默认是开发版。
- 只有应用创建者可以使用。
- 用于开发调试。

### 阶段 2：测试版（指定成员可见）

1. 在「版本管理」创建测试版本。
2. 指定测试成员（最多 50 个 open_id）。
3. 测试成员可以在自己的飞书看到应用。

### 阶段 3：正式版（企业内全员可见）

1. 测试通过后，创建正式版本。
2. 提交审核（仅企业自建应用需要）。
3. 企业管理员审批通过后，全员可见。

## 七、安全实践

### 1. 密钥管理

```python
# ❌ 错误：硬编码
APP_SECRET = "secret_xxxxxxxx"

# ✅ 正确：环境变量
import os
APP_SECRET = os.environ.get("FEISHU_APP_SECRET")

# ✅ 更好：密钥管理服务（KMS）
from your_kms_client import get_secret
APP_SECRET = get_secret("feishu-app-secret")
```

### 2. 最小权限原则

只申请必需的权限，不多申请。

**示例**：
- 如果只需要读妙记，只申请 `minutes:minutes:readonly`，不申请 `:write`。
- 如果只需要任务写，不需要读申请读权限外的其他权限。

### 3. IP 白名单（可选）

如果应用部署在固定 IP 的服务器，可以配置 IP 白名单：

1. 在「安全设置」添加可信 IP。
2. 飞书只接受来自白名单 IP 的 Webhook 调用。

### 5. 频率限制应对

```python
class RateLimiter:
    """频率限制器"""
    
    def __init__(self):
        # 各 API 的 QPS 限制
        self.limits = {
            "minutes_artifact": 5,
            "task": 10,
            "bitable": 10,
            "vc": 10
        }
        self.last_calls = {}  # api → timestamp list
    
    async def wait_if_needed(self, api_name: str):
        """如需要，等待"""
        limit = self.limits.get(api_name, 10)
        now = time.time()
        
        if api_name not in self.last_calls:
            self.last_calls[api_name] = []
        
        # 清理 1 秒前的记录
        self.last_calls[api_name] = [
            t for t in self.last_calls[api_name] if t > now - 1
        ]
        
        # 如果达到限制，等待
        if len(self.last_calls[api_name]) >= limit:
            sleep_time = 1 - (now - self.last_calls[api_name][0])
            if sleep_time > 0:
                await asyncio.sleep(sleep_time)
        
        self.last_calls[api_name].append(now)
```

## 九、我的实战经验

### 经验 1：预留充足时间

权限审核 3-5 工作日是常态，**绝不能等到上线前才申请**。提前 2 周申请。

### 经验 2：申请理由要详细

申请理由不详细会被打回。说明：用途、使用范围、使用频率、数据安全承诺。

### 经验 3：分阶段申请

不要一次性申请所有权限。先申请核心权限（如妙记 + 任务），上线后再申请额外权限。

### 经验 4：备份 token 管理

```python
# 多实例部署：用 Redis 集中管理 token
TOKEN_KEY = "feishu:tenant_access_token"

async def get_token_redis(redis_client, app_id, app_secret):
    cached = await redis_client.get(TOKEN_KEY)
    if cached:
        return cached.decode()
    
    # 申请新 token
    token = await get_token(app_id, app_secret)
    
    # 缓存 1.5 小时（提前 30 分钟过期）
    await redis_client.setex(TOKEN_KEY, 5400, token)
    
    return token
```

### 经验 5：定期轮换 app_secret

每隔 6-12 个月轮换 app_secret（飞书后台可重置）。

## 十、本章关键 takeaway

- 飞书高级权限审核是上线瓶颈，**预留 3-5 工作日**。
- 申请理由要详细说明用途、范围、频率、安全承诺。
- tenant_access_token 有效期 2 小时，必须缓存并自动刷新。
- 事件订阅推荐生产用 Webhook（需要公网 HTTPS），开发用 WebSocket。
- 应用发布分三阶段：开发版 → 测试版 → 正式版。
- 安全实践：密钥管理、最小权限、IP 白名单、审计日志、频率限制。
- 定期监控 API 错误率、配额使用、Webhook 成功率。
