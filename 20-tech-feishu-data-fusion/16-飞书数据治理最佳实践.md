# 16 - 飞书数据治理最佳实践

> **TL;DR**：飞书数据治理（权限、合规、备份、生命周期）是企业 AI 应用**长期稳定**的基础。本篇讲清楚 5 大治理维度。

---

## 一、数据治理的 5 大维度

### 维度 1：权限管理（Authorization）

#### 谁可以访问什么数据

- **企业级权限**：管理员设置全员权限。
- **应用级权限**：自建应用的 API 权限。
- **数据级权限**：单个多维表格 / 文档的协作者。

#### 实战建议

- **最小权限原则**：只给应用必需的权限。
- **分级授权**：核心数据仅高管可访问，敏感数据仅责任人可访问。
- **定期审计**：每季度 review 权限，清理离职员工。

### 维度 2：数据分类（Classification）

#### 数据敏感度分级

| 级别 | 描述 | 例子 | 处理 |
|---|---|---|---|
| L1 公开 | 所有人都可看 | 产品文档 | 无特殊处理 |
| L2 内部 | 公司内可看 | 内部 wiki | 不公开 |
| L3 敏感 | 部分员工可看 | 客户信息 | 脱敏 + 权限 |
| L4 机密 | 仅核心员工可看 | 财务数据 | 加密 + 审计 |
| L5 绝密 | 仅高管 | 战略规划 | 严格审计 |

#### 实战建议

- 强制数据分类标签。
- L3+ 数据自动脱敏。
- L4+ 数据加密存储。

### 维度 3：合规管理（Compliance）

#### 中国合规

- 《数据安全法》：数据分级分类保护。
- 《个人信息保护法》：个人信息处理规则。
- 《网络安全法》：网络运营者义务。

#### 国际合规

- **GDPR**（欧盟）：数据保护、用户权利。
- **CCPA**（加州）：消费者隐私权。
- **HIPAA**（医疗）：医疗数据保护。

#### 实战建议

- 飞书多维表格**不支持**自动合规检查，需**自建**。
- 用户请求删除个人数据时，必须能**完全删除**（含历史、缓存、备份）。
- 数据跨境传输需符合当地法规。

### 维度 4：备份与恢复（Backup & Recovery）

#### 备份策略

- **每日自动备份**：所有多维表格的"全量快照"。
- **每周深度备份**：含结构（字段、视图、自动化）。
- **每月归档**：长期保留。

#### 备份存储

- 飞书 API 导出 → S3 / OSS。
- **异地备份**：至少 2 个地理位置。
- **加密存储**：AES-256。

#### 恢复演练

- **每月演练**：从备份恢复测试环境。
- **每季度演练**：完整灾难恢复流程。

### 维度 5：生命周期管理（Lifecycle）

#### 数据生命周期

```
创建 → 使用 → 归档 → 删除
```

- **创建**：记录创建时间和创建人。
- **使用**：访问日志、修改日志。
- **归档**：超过使用期后**移到归档存储**。
- **删除**：超过保留期后**永久删除**。

#### 保留策略

| 数据类型 | 保留期 | 原因 |
|---|---|---|
| 客户对话 | 3 年 | 合规 |
| 财务数据 | 7 年 | 税务合规 |
| 操作日志 | 1 年 | 调试 |
| 备份数据 | 90 天 | 节省成本 |

## 二、权限设计实战

### 多维表格权限

```python
class BitablePermissionManager:
    """多维表格权限管理"""
    
    PERMISSION_LEVELS = {
        "view": "只读",
        "edit": "可编辑",
        "full_access": "完全控制"
    }
    
    async def grant(self, app_token, open_id, level):
        """授予权限"""
        await self.feishu.create_app_permission_member(
            app_token=app_token,
            member_id=open_id,
            perm=level
        )
    
    async def revoke(self, app_token, open_id):
        """撤销权限"""
        await self.feishu.delete_app_permission_member(
            app_token=app_token,
            member_id=open_id
        )
    
    async def audit(self, app_token):
        """审计权限"""
        members = await self.feishu.list_app_permission_members(app_token)
        for m in members:
            # 检查是否还在公司
            user = await self.feishu.get_user(m.member_id)
            if not user.is_active:
                await self.revoke(app_token, m.member_id)
                logger.info(f"Revoked permission for inactive user {m.member_id}")
```

## 三、数据脱敏实战

### PII 自动识别

```python
class PIIDetector:
    """PII 自动识别"""
    
    PATTERNS = {
        "id_card": r'\b\d{17}[\dXx]\b',      # 中国身份证
        "phone": r'\b1[3-9]\d{9}\b',          # 手机号
        "email": r'[\w.-]+@[\w.-]+',          # 邮箱
        "bank_card": r'\b\d{16,19}\b',       # 银行卡
        "address": r'[\u4e00-\u9fa5]{2,8}(?:省|市|区|县)',
        "name_cn": r'[\u4e00-\u9fa5]{2,4}(?=[，。\s])',
    }
    
    def detect(self, text: str) -> List[Dict]:
        """检测 PII"""
        findings = []
        for pii_type, pattern in self.PATTERNS.items():
            for match in re.finditer(pattern, text):
                findings.append({
                    "type": pii_type,
                    "value": match.group(),
                    "position": match.span()
                })
        return findings
    
    def redact(self, text: str) -> str:
        """脱敏"""
        for pii_type, pattern in self.PATTERNS.items():
            replacement = f"[{pii_type.upper()}]"
            text = re.sub(pattern, replacement, text)
        return text
```

### 飞书 API 脱敏

```python
async def safe_meeting_extraction(minute_token):
    """安全的妙记提取（脱敏后处理）"""
    artifact = await feishu.get_minutes_artifact(minute_token)
    
    # 1. 检测 PII
    detector = PIIDetector()
    
    # 2. 脱敏 summary
    artifact["summary"] = detector.redact(artifact["summary"])
    
    # 3. 脱敏 todo_list
    for todo in artifact.get("todo_list", []):
        todo["content"] = detector.redact(todo["content"])
        todo["owner"] = detector.redact(todo["owner"])
    
    # 4. 记录 PII 检测结果
    pii_count = len(detector.detect(artifact["summary"]))
    if pii_count > 0:
        logger.warning(f"妙记 {minute_token} 含 {pii_count} 处 PII")
    
    return artifact
```

## 四、备份与恢复实战

### 自动备份脚本

```python
class BitableBackup:
    """多维表格备份"""
    
    async def backup_all_tables(self):
        """备份所有多维表格"""
        tables = await self.list_all_tables()
        
        backup_id = f"backup_{datetime.now().strftime('%Y%m%d_%H%M%S')}"
        
        for table in tables:
            # 1. 备份记录
            records = await self.feishu.list_bitable_records(
                table["app_token"], table["table_id"]
            )
            
            # 2. 备份 schema
            schema = await self.feishu.get_bitable_schema(
                table["app_token"], table["table_id"]
            )
            
            # 3. 备份视图
            views = await self.feishu.list_views(
                table["app_token"], table["table_id"]
            )
            
            # 4. 存储到 S3
            backup_data = {
                "table": table,
                "records": records,
                "schema": schema,
                "views": views,
                "backup_time": datetime.utcnow().isoformat()
            }
            
            s3_path = f"s3://ai-work-backups/bitable/{backup_id}/{table['name']}.json"
            await s3.put_object(s3_path, json.dumps(backup_data, ensure_ascii=False))
            
            logger.info(f"Backed up {table['name']} to {s3_path}")
        
        # 5. 清理 90 天前的备份
        await self.cleanup_old_backups(days=90)
```

### 恢复演练

```python
async def disaster_recovery_drill():
    """灾难恢复演练"""
    
    # 1. 从 S3 拉取最新备份
    backup = await s3.get_object("s3://ai-work-backups/bitable/latest.json")
    
    # 2. 创建新多维表格（测试环境）
    test_table = await feishu.create_bitable(
        name=f"test_restore_{datetime.now().strftime('%Y%m%d')}",
        records=backup["records"],
        schema=backup["schema"]
    )
    
    # 3. 验证数据完整性
    original_count = len(backup["records"])
    restored_count = len(test_table["records"])
    assert original_count == restored_count
    
    # 4. 验证关键字段
    for original in backup["records"][:10]:  # 抽检 10 条
        restored = next(
            r for r in test_table["records"]
            if r["record_id"] == original["record_id"]
        )
        for key in ["项目状态", "负责人", "进展"]:
            assert original["fields"].get(key) == restored["fields"].get(key)
    
    logger.info("Disaster recovery drill PASSED")
```

```yaml

  - [ ] 用户请求删除时，30 天内完全删除数据
```

## 六、数据生命周期管理

### 自动归档脚本

```python
class DataLifecycleManager:
    """数据生命周期管理"""
    
    async def archive_old_records(self):
        """归档老记录"""
        cutoff_date = datetime.now() - timedelta(days=365)
        
        tables = await self.list_all_tables()
        for table in tables:
            records = await self.feishu.list_bitable_records(
                table["app_token"], table["table_id"]
            )
            
            for record in records:
                if self.is_old(record, cutoff_date):
                    # 移到归档表
                    await self.move_to_archive(record)
                    logger.info(f"Archived record {record['record_id']}")
    
    async def delete_expired_records(self):
        """删除过期记录"""
        cutoff_date = datetime.now() - timedelta(days=2555)  # 7 年
        
        tables = await self.list_all_tables()
        for table in tables:
            records = await self.feishu.list_bitable_records(
                table["app_token"], table["table_id"]
            )
            
            for record in records:
                if self.is_expired(record, cutoff_date):
                    # 删除
                    await self.feishu.delete_bitable_record(
                        table["app_token"], table["table_id"],
                        record["record_id"]
                    )
                    logger.info(f"Deleted expired record {record['record_id']}")
```

## 八、本章关键 takeaway

- **5 大治理维度**：权限、分类、合规、备份、生命周期。
- **权限管理**：最小权限、分级授权、定期审计。
- **数据分类**：5 级分类（L1 公开 → L5 绝密）。
- **合规**：GDPR / PIPL / HIPAA 各有清单。
- **备份**：每日全量 + 每周深度 + 每月归档，异地加密。
- **数据脱敏**：PII 自动识别 + 飞书 API 集成。
- **生命周期**：归档老数据、删除过期数据。
- **监控告警**：备份失败、未授权访问、PII 泄露等关键事件。
