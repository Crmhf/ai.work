## 选择标准

- **质量优先**：只收录高质量、长期有价值的资源。
- **实用导向**：每个资源都说明"为什么值得用 / 读 / 关注"。
- **持续更新**：资源会过时，我会定期更新。

## 适用人群

- **入门**：从必用工具 + 必关注社区开始。
- **进阶**：读必读论文 + 深入特定工具。
- **研究者**：跟踪最新论文 + 关注前沿社区。
