# 02 - 必用工具清单

> AI Agent 工程师**高频使用的 30 个工具**。按类别整理，每个工具给出**用途、为什么用、链接**。

---

## 一、编码工具（5 个）

### 1. Cursor

- **用途**：AI 增强的 IDE，Composer 跨文件编辑。
- **为什么用**：我每天 80% 的编码时间在 Cursor。**Composer 改变编码方式**。
- **链接**：https://cursor.com

### 2. Claude Code（CLI）

- **用途**：命令行 AI 助手，跑批处理、自动化脚本。
- **为什么用**：Cursor 不擅长的批量任务用 Claude Code。
- **链接**：https://claude.ai/claude-code

### 3. Aider / Continue

- **用途**：Git-aware 的 AI 编码工具。
- **为什么用**：开源自托管，适合企业部署。
- **链接**：https://aider.chat / https://continue.dev

### 4. Cline / Roo Code

- **用途**：VS Code AI 插件，能跑多步任务。
- **为什么用**：Cursor 替代品，开源。
- **链接**：https://github.com/cline/cline

### 5. GitHub Copilot

- **用途**：AI 代码补全。
- **为什么用**：行业标杆，集成度高。
- **链接**：https://github.com/features/copilot

---

## 二、Agent 框架（5 个）

### 6. OpenClaw

- **用途**：多 Agent 工程编排。
- **为什么用**：Lobster DSL 写工作流，Open API 集成。
- **特点**：声明式工作流，工程化最强。
- **链接**：https://openclaw.dev

### 7. LangGraph

- **用途**：LangChain 团队的多 Agent 框架。
- **为什么用**：图结构编排，灵活。
- **特点**：代码优先，深度集成 LangChain 生态。
- **链接**：https://langchain-ai.github.io/langgraph/

### 8. AutoGen

- **用途**：微软的对话式多 Agent 框架。
- **为什么用**：灵活，对话驱动。
- **特点**：适合研究 / 实验，不适合工程化生产。
- **链接**：https://github.com/microsoft/autogen

### 9. CrewAI

- **用途**：基于角色的多 Agent 框架。
- **为什么用**：易上手，角色定义清晰。
- **特点**：适合中小项目。
- **链接**：https://github.com/joaomdmoura/crewAI

### 10. MetaGPT

- **用途**：软件工程多 Agent 团队。
- **为什么用**：经典 SOP（产品 → 架构 → 编码 → QA）。
- **特点**：开源，研究参考。
- **链接**：https://github.com/geekan/MetaGPT

---

## 三、LLM 模型（5 个）

### 11. OpenAI API（GPT-4 / GPT-4 Turbo / GPT-3.5）

- **用途**：通用 LLM。
- **为什么用**：行业标杆，工具丰富。
- **链接**：https://openai.com/api

### 12. Anthropic API（Claude 3 Opus / Sonnet / Haiku）

- **用途**：通用 LLM，长文本处理强。
- **为什么用**：200K 上下文，安全性好。
- **链接**：https://anthropic.com

### 13. Google Gemini API

- **用途**：多模态 LLM。
- **为什么用**：图像 / 视频处理领先。
- **链接**：https://ai.google.dev

### 14. Ollama

- **用途**：本地 LLM 部署。
- **为什么用**：一键运行 Llama、Mistral 等开源模型。
- **链接**：https://ollama.com

### 15. vLLM

- **用途**：高性能 LLM 推理服务。
- **为什么用**：生产环境部署开源模型的最佳选择。
- **链接**：https://github.com/vllm-project/vllm

---

## 四、向量数据库与 RAG（4 个）

### 16. Pinecone

- **用途**：托管向量数据库。
- **为什么用**：易用、稳定。
- **链接**：https://www.pinecone.io

### 17. Weaviate

- **用途**：开源向量数据库。
- **为什么用**：自托管，模块化。
- **链接**：https://weaviate.io

### 18. Milvus

- **用途**：大规模向量数据库。
- **为什么用**：亿级向量支持，企业级。
- **链接**：https://milvus.io

### 19. Chroma

- **用途**：轻量级向量数据库。
- **为什么用**：本地开发友好，Python 生态。
- **链接**：https://www.trychroma.com

---

## 五、可观测性与监控（4 个）

### 20. LangSmith

- **用途**：LangChain 官方可观测性平台。
- **为什么用**：LLM 调用 trace、自动评估。
- **链接**：https://smith.langchain.com

### 21. Langfuse

- **用途**：开源 LLM 可观测性平台。
- **为什么用**：自托管，兼容 OpenAI / Anthropic。
- **链接**：https://langfuse.com

### 22. Helicone

- **用途**：LLM 调用监控 + 缓存。
- **为什么用**：快速接入，缓存功能强。
- **链接**：https://helicone.ai

### 23. Phoenix (Arize)

- **用途**：LLM 评估 + 可观测性。
- **为什么用**：开源 + 评估功能强。
- **链接**：https://phoenix.arize.com

## 七、MCP 与工具生态（2 个）

### 27. Model Context Protocol (MCP)

- **用途**：Anthropic 推动的工具协议。
- **为什么用**：**未来 Agent 工具的标准**。
- **链接**：https://modelcontextprotocol.io

### 28. Composio

- **用途**：第三方 SaaS 工具集成平台（基于 MCP）。
- **为什么用**：500+ 工具一键接入 Agent。
- **链接**：https://composio.dev

## 八、专项工具（2 个）

### 29. lark-cli（飞书官方）

- **用途**：飞书开放平台 CLI。
- **为什么用**：22+ Skills 直接调用飞书 API。
- **链接**：https://github.com/larksuite/lark-cli

### 30. Open Interpreter

- **用途**：本地代码执行 Agent。

## 工具选择决策

### 我应该用什么 LLM？

| 任务 | 推荐 |
|---|---|
| 复杂推理 | GPT-4 / Claude 3 Opus |
| 通用任务 | GPT-4 Turbo / Claude 3 Sonnet |
| 简单任务 | GPT-3.5 / Claude 3 Haiku |
| 本地部署 | Llama 3 / Qwen / DeepSeek |
| 长文本 | Claude 3 (200K) / Gemini 1.5 |

### 我应该用什么 Agent 框架？

| 场景 | 推荐 |
|---|---|
| 生产级多 Agent | OpenClaw / LangGraph |
| 快速实验 | AutoGen / CrewAI |
| 软件工程团队 | MetaGPT / OpenClaw |
| 单 Agent 工具 | LangChain |

### 我应该用什么向量数据库？

| 规模 | 推荐 |
|---|---|
| < 100K 向量 | Chroma |
| 100K - 10M | Pinecone / Weaviate |
| > 10M | Milvus |

---

## 我的工具栈（实际使用）

```
编码：Cursor（主力）+ Claude Code（批处理）
Agent：OpenClaw（多 Agent）+ LangGraph（实验）
LLM：GPT-4 Turbo（主力）+ Claude 3 Sonnet（长文本）
向量：Pinecone（生产）+ Chroma（本地开发）
可观测性：LangSmith + 自建 Prometheus
Prompt：LangSmith Prompt Hub
MCP：Composio
```

---

## 本章关键 takeaway

- 30 个工具覆盖**编码、Agent、LLM、RAG、可观测、Prompt、MCP**7 大类别。
- **编码**：Cursor 是 2026 年必用。
- **Agent**：OpenClaw / LangGraph 是生产首选。
- **可观测性**：LangSmith 是 LLM 时代的"必备"。
- **工具选择看场景**：生产用稳定、学习用灵活。
