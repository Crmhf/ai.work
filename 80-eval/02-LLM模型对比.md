# 02 - LLM 模型对比

> **TL;DR**：本篇对比 **10 个主流 LLM 模型**（GPT-4、Claude 3、Gemini、Llama 3、Qwen、DeepSeek 等），从 **能力、价格、上下文窗口、速度、适用场景** 5 个维度分析。

---

## 一、为什么需要对比

- **选 LLM**：根据任务选最合适的模型。
- **控制成本**：了解每个模型的"性价比"。
- **应对变化**：模型迭代快，需要持续对比。

---

## 二、10 个主流模型概览

### 1. GPT-4（OpenAI）

- **版本**：GPT-4、GPT-4 Turbo、GPT-4o。
- **上下文**：128K（GPT-4 Turbo）。
- **价格**：$0.01-0.03/1K input、$0.03-0.06/1K output。
- **优势**：综合能力最强、工具生态最好。
- **劣势**：价格高、闭源。
- **适用**：复杂推理、复杂任务。
- **链接**：https://openai.com/api

### 2. GPT-4o（OpenAI）

- **版本**：GPT-4o、GPT-4o mini。
- **上下文**：128K。
- **价格**：$0.005/0.015 per 1K（4o）、$0.00015/0.0006 per 1K（mini）。
- **优势**：速度快（实时响应）、多模态、价格适中。
- **劣势**：能力略低于 GPT-4 Turbo。
- **适用**：实时对话、多模态任务。
- **链接**：https://openai.com/api

### 3. Claude 3 Opus（Anthropic）

- **上下文**：200K。
- **价格**：$0.015/0.075 per 1K。
- **优势**：长上下文、安全性强、写作能力强。
- **劣势**：价格高。
- **适用**：长文本分析、合规场景、高质量写作。
- **链接**：https://anthropic.com

### 4. Claude 3.5 Sonnet（Anthropic）

- **上下文**：200K。
- **价格**：$0.003/0.015 per 1K。
- **优势**：综合能力强（接近 Opus）、价格合理、速度快。
- **劣势**：复杂推理略低于 Opus。
- **适用**：通用 Agent 任务（SWE-bench 49% 解决率）。
- **推荐**：**性价比最高的旗舰模型之一**。

### 5. Claude 3 Haiku（Anthropic）

- **上下文**：200K。
- **价格**：$0.00025/0.00125 per 1K。
- **优势**：超快、超便宜。
- **劣势**：能力较弱。
- **适用**：简单任务（分类、提取）、高频调用。

### 6. Gemini 1.5 Pro（Google）

- **上下文**：1M-2M tokens。
- **劣势**：质量参差不齐。
- **价格**：$0.00125/0.005 per 1K（128K 以内）。
- **优势**：超长上下文、多模态。
- **劣势**：生态不如 OpenAI。
- **适用**：超长文档、视频分析。

### 7. Gemini 1.5 Flash（Google）

- **上下文**：1M tokens。
- **价格**：$0.000075/0.0003 per 1K。
- **优势**：超快、超便宜、超长上下文。
- **适用**：高频简单任务。

### 8. Llama 3.1 405B（Meta，开源）

- **上下文**：128K。
- **价格**：自建（GPU 成本）或第三方 API（如 Groq、Together）。
- **优势**：开源、可私有化、能力接近 GPT-4。
- **劣势**：自建成本高、需要 GPU。
- **适用**：数据敏感场景、大量调用。
- **链接**：https://llama.meta.com

### 9. Qwen 2.5 72B（阿里，开源）

- **上下文**：128K。
- **价格**：自建或 API。
- **优势**：中文能力强、开源、价格便宜。
- **劣势**：英文略弱于 Llama。
- **适用**：中文场景。
- **链接**：https://qwen.alibaba.com

### 10. DeepSeek V3（DeepSeek，开源）

- **上下文**：64K。
- **价格**：API 极便宜（约 GPT-4 Turbo 的 1/10）。
- **优势**：价格低、推理强（数学、代码）。
- **劣势**：生态较小。
- **适用**：成本敏感场景、推理任务。
- **链接**：https://deepseek.com

## 五、按场景推荐

### 推荐 1：复杂 Agent 任务（软件工程、研究）

- **首选**：Claude 3.5 Sonnet（综合能力 + 性价比）。
- **次选**：GPT-4 Turbo。
- **开源**：Llama 3.1 405B。

### 推荐 2：实时对话 / 多模态

- **首选**：GPT-4o（速度快 + 多模态）。
- **次选**：Gemini 1.5 Flash（极快 + 便宜）。

### 推荐 3：高频简单任务（分类、提取）

- **首选**：GPT-4o mini 或 Claude 3 Haiku。
- **价格**：约 GPT-4 的 1/100。

### 推荐 4：长文档分析

- **首选**：Gemini 1.5 Pro（1M 上下文）。
- **次选**：Claude 3 Opus（200K 上下文）。

### 推荐 5：中文场景

- **首选**：Qwen 2.5 72B（开源）或 Qwen API。
- **次选**：DeepSeek V3（便宜 + 推理强）。

### 推荐 6：数据敏感 / 私有化

- **首选**：Llama 3.1 405B（开源）或 Qwen 2.5。
- **部署**：vLLM / Ollama。

### 推荐 7：成本敏感（量大）

- **首选**：DeepSeek V3（极便宜）或 Gemini 1.5 Flash。
- **价格**：约 GPT-4 的 1/30。

## 六、我的实战选型经验

### 我的主力 LLM 栈

```
主力：Claude 3.5 Sonnet
  - Agent 任务（SWE-bench 49%）
  - 综合任务（写作、分析）
  - 价格合理

辅助：GPT-4o
  - 实时对话
  - 多模态任务（图像理解）

便宜：GPT-4o mini / Claude 3 Haiku
  - 简单分类、提取
  - 高频调用

本地：Llama 3.1 8B（Ollama）
  - 离线场景
  - 数据敏感
```

### 切换策略

- **平时**：Claude 3.5 Sonnet（主力）。
- **实时**：GPT-4o（速度）。
- **量大**：GPT-4o mini / Haiku（成本）。
- **超长**：Gemini 1.5 Pro（上下文）。

## 八、本章关键 takeaway

- 10 个主流模型覆盖**闭源 + 开源 + 多模态 + 实时 + 长文本**全谱。
- **能力接近**的情况下，**价格差异 100 倍以上**。
- **Claude 3.5 Sonnet** 是 2026 年综合性价比最高的旗舰。
- **GPT-4o mini / Claude 3 Haiku** 是高频任务的首选。
- **开源 + 自建**适合数据敏感 + 大规模场景。
- **选 LLM = 任务复杂度 × 上下文长度 × 成本预算** 三维决策。
