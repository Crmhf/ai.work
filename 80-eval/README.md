## 评估的 3 个层级

### 1. 模型层评估

评估 LLM 本身的能力：理解、推理、生成、知识等。

**基准**：MMLU、HELM、HumanEval、GSM8K 等。

### 2. Agent 层评估

评估 Agent 完成实际任务的能力：软件工程、研究、客服等。

**基准**：SWE-bench、AgentBench、WebArena 等。

### 3. 产品层评估

评估 AI 产品的用户体验和商业价值：留存、转化、NPS 等。

**方法**：A/B 测试、用户调研、业务指标。

---

## 选择策略

- **选 LLM**：用模型层评估 + 自己的评测集。
- **选 Agent 框架**：用 Agent 层评估 + 业务场景测试。
- **优化 AI 产品**：用产品层评估 + 用户反馈。

## 写作约定

- **数据说话**：每个对比都尽量给数据（性能、价格、benchmark）。
- **场景化**：不同场景下结论可能不同，要说明适用场景。
- **持续更新**：LLM 迭代快，每季度 review。
