# 10-tech-multi-agent — 多 Agent 工程编排

> 基于 OpenClaw 多 Agent 工程编排完整方案的**实战级拆解**。
> 涵盖架构设计、Agent 角色、调度引擎、通信协议、工作流 DSL、可观测性、部署运维。
> 这是我目前在做"AI 团队自动化"项目时最依赖的技术骨架。

---

## 核心思想（一句话版）

> **Orchestrator + Specialist Fleet + 产物驱动通信 + 质量门禁 + 自愈机制**
> — 指挥官拆活、专业团队执行、用"产物"而非"对话"协作、每步有检查、错了能回滚。

## 适用场景

✅ **适合用这套范式**：
- 中小型全栈应用的端到端开发（Web / App / 小程序）
- MVP 快速原型构建与迭代
- 已有产品的功能模块扩展与重构
- 技术栈统一、架构清晰的标准化项目

⚠️ **不适合**：
- 强实时性要求的系统（Agent 调度有秒级延迟）
- 强合规、强审计场景（Agent 决策不可解释风险）
- 超大规模并发（千级以上 Agent 协同未验证）
