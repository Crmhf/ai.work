# 05 - 调度决策引擎实现

> **TL;DR**：调度决策引擎是 Orchestrator 的"决策中心"。它根据任务依赖特征自动选择执行模式（串行/并行/波次/条件/人工审批），让复杂任务跑得又快又稳。

---

## 一、5 种执行模式

### 模式 1：串行（Sequential）

**触发条件**：下游任务强依赖上游任务的完整产物（数据耦合紧）。

**示例**：
- 架构设计 → 编码实现（编码需要完整 API Spec）
- PRD 编写 → UI 设计（UI 需要完整 PRD）

**OpenClaw 实现**：

```yaml
# lobsters/sequential_pattern.yaml
name: "Architecture → Coding"
mode: sequential
steps:
  - agent: architect
    task: "T3.2: Design API Spec"
    output: "shared/03_Arch/APISpec.yaml"
  - agent: coder_backend
    task: "T4.1: Implement Backend"
    input: "shared/03_Arch/APISpec.yaml"
    output: "/backend/"
```

**实现核心**：pipeline pattern + `sessions_send`。

---

### 模式 2：并行（Parallel）

**触发条件**：任务间无依赖且资源不冲突。

**示例**：
- T2.2 / T2.3 / T2.4（三个页面同时设计）
- Frontend Coder / Backend Coder 同时实现

**OpenClaw 实现**：

```yaml
# lobsters/parallel_pattern.yaml
name: "Design 3 Pages Simultaneously"
mode: parallel
steps:
  - agent: ui_designer
    task: "T2.2: Design Home Page"
    output: "shared/02_UI/Wireframes/HomePage.md"
  - agent: ui_designer
    task: "T2.3: Design Product Detail"
    output: "shared/02_UI/Wireframes/ProductDetail.md"
  - agent: ui_designer
    task: "T2.4: Design Cart & Checkout"
    output: "shared/02_UI/Wireframes/CartCheckout.md"
```

**实现核心**：parallel pattern + 多个 `agentToAgent` 同时调用。

**注意**：并行任务可能抢占同一资源（如 `DesignSystem.md`），要加锁或串行化共享资源访问。

---

### 模式 3：波次（Wave）

**触发条件**：部分依赖形成层级（典型场景）。

**示例**：

```
Wave 2: T2.1 (设计系统) → [T2.2, T2.3, T2.4] (页面线框图)
Wave 3: T3.1 (系统架构) → T3.2 (API Spec)
Wave 4: [T4.1 (前端), T4.2 (后端)]（依赖 Wave 2 + Wave 3 全部完成）
```

**OpenClaw 实现**：

```yaml
# lobsters/wave_pattern.yaml
name: "UI Design Wave + Architecture Wave + Implementation Wave"
mode: wave
waves:
  - wave: 2
    mode: parallel
    tasks: [T2.2, T2.3, T2.4]
    precondition: "T2.1 == COMPLETED"
  - wave: 3
    mode: sequential
    tasks: [T3.1, T3.2]
  - wave: 4
    mode: parallel
    tasks: [T4.1, T4.2]
    precondition: "Wave 2 + Wave 3 == COMPLETED"
```

**实现核心**：混合模式（波次内并行，波次间串行）。

---

### 模式 4：条件（Conditional）

**触发条件**：下游路径依赖上游结果（如测试通过则部署，失败则修复）。

**示例**：

```yaml
# lobsters/conditional_pattern.yaml
name: "Test → Deploy or Fix"
mode: conditional
branches:
  - condition: "test_result == 'PASS'"
    then:
      - agent: devops
        task: "T6.1: Deploy"
  - condition: "test_result == 'FAIL'"
    then:
      - agent: coder_backend  # 或者 coder_frontend，根据 bug 归属
        task: "T5.2: Fix Bug"
        loop_until: "test_result == 'PASS'"
        max_iterations: 3
      - if_loop_fails:
          - action: "escalate_to_human"
```

**实现核心**：Lobster DSL 的 `if/else` 条件分支。

---

### 模式 5：人工审批（HITL, Human-in-the-Loop）

**触发条件**：关键决策点（PRD 确认、架构评审、上线审批）。

**示例**：

```yaml
# lobsters/hitl_pattern.yaml
name: "Pause for PRD Approval"
mode: hitl
steps:
  - agent: product
    task: "T1.1: Write PRD"
    output: "shared/01_PRD/PRD.md"
  - action: "pause_for_approval"
    artifact: "shared/01_PRD/PRD.md"
    approvers: ["user"]
    timeout: "24h"
    on_timeout: "escalate"
  - agent: ui_designer
    task: "T2.1: Define Design System"
    depends_on_approval: true
```

**实现核心**：Lobster DSL 的 `pause_for_approval` 节点。

## 二、自动模式选择算法

Orchestrator 收到任务图后，自动选择每个 wave 的执行模式：

```python
def select_execution_mode(wave: List[Task]) -> ExecutionMode:
    """根据任务依赖特征选择执行模式"""
    
    # 单任务 → 串行
    if len(wave) == 1:
        return ExecutionMode.SEQUENTIAL
    
    # 所有任务无共享资源 → 并行
    if not has_shared_resources(wave):
        return ExecutionMode.PARALLEL
    
    # 任务有共享资源但可串行化 → 串行
    if can_serialize_shared_resources(wave):
        return ExecutionMode.SEQUENTIAL
    
    # 复杂依赖关系 → 波次
    return ExecutionMode.WAVE
```

**模式选择决策表**：

| 任务数 | 共享资源 | 模式 |
|---|---|---|
| 1 | - | SEQUENTIAL |
| > 1 | 无 | PARALLEL |
| > 1 | 有，但可序列化 | SEQUENTIAL |
| > 1 | 有，复杂 | WAVE |
| 含 HITL 节点 | - | HITL |
| 含 if/else 分支 | - | CONDITIONAL |

## 三、调度器状态机

Orchestrator 的执行过程是一个状态机：

```
┌─────────┐     分解成功      ┌─────────┐
│  IDLE   │ ───────────────→ │ PLANNING│
└─────────┘                  └────┬────┘
                                  │
              依赖图构建完成       ▼
                            ┌─────────┐
                            │READY_TO_│
                            │ EXECUTE │
                            └────┬────┘
                                 │
                ┌────────────────┼────────────────┐
                ▼                ▼                ▼
          ┌──────────┐     ┌──────────┐     ┌──────────┐
          │ EXECUTING│     │  PAUSED  │     │ BLOCKED  │
          │  WAVE N  │     │(等审批) │     │(等澄清)  │
          └────┬─────┘     └────┬─────┘     └────┬─────┘
               │                │                │
               ▼                ▼                ▼
       ┌───────────────┐   (审批回来)      (澄清回来)
       │  质量门禁检查  │
       └───────┬───────┘
               │
       ┌───────┴────────┐
       ▼                ▼
   ┌────────┐      ┌────────┐
   │ PASSED │      │ FAILED │
   └───┬────┘      └───┬────┘
       │                │
       ▼                ▼
   (下一 wave)    (回溯/重试)
                       │
               ┌───────┴────────┐
               ▼                ▼
          ┌────────┐      ┌─────────┐
          │ RETRY  │      │ESCALATE │
          │ (≤3次) │      │  HUMAN  │
          └────────┘      └─────────┘
```

### 状态转换详解

**IDLE → PLANNING**：收到用户需求，开始分解。
**PLANNING → READY_TO_EXECUTE**：依赖图构建完成。
**READY_TO_EXECUTE → EXECUTING**：开始执行 wave。
**EXECUTING → 质量门禁检查**：wave 内所有任务完成。
**门禁 PASSED → EXECUTING（下一个 wave）**：进入下一波次。
**门禁 FAILED → RETRY 或 ESCALATE**：回溯到上游 Agent 修复，或升级人工。
**EXECUTING → PAUSED**：遇到 HITL 节点，等待人类审批。
**PAUSED → EXECUTING**：审批通过，继续。
**EXECUTING → BLOCKED**：遇到 CLARIFICATION，需要澄清。
**BLOCKED → EXECUTING**：澄清完成，继续。

## 四、调度器核心代码

```python
# orchestrator/core/scheduler.py
import asyncio
from typing import Dict, List
from dataclasses import dataclass
from enum import Enum

class ExecutionMode(Enum):
    SEQUENTIAL = "sequential"
    PARALLEL = "parallel"
    WAVE = "wave"
    CONDITIONAL = "conditional"
    HITL = "hitl"

@dataclass
class DispatchResult:
    task_id: str
    agent_id: str
    status: str
    outputs: List[str]
    error: str = None
    duration_seconds: float = 0.0

class AgentScheduler:
    """多 Agent 调度器"""
    
    def __init__(self, orchestrator_agent, project_state_path: str):
        self.orchestrator = orchestrator_agent
        self.state_path = project_state_path
        self.state = self._load_state()
        self.active_tasks: Dict[str, asyncio.Task] = {}
    
    async def execute_project(self, tasks: List[Task]) -> bool:
        """执行完整项目"""
        waves = self.decomposer.build_waves(tasks)
        
        for wave_idx, wave in enumerate(waves):
            print(f"🌊 Wave {wave_idx + 1}/{len(waves)}: {len(wave)} tasks")
            
            # 更新状态
            self.state["current_wave"] = wave_idx + 1
            self.state["status"] = "RUNNING"
            self._save_state()
            
            # 选择执行模式
            mode = self._select_mode(wave)
            
            # 执行
            if mode == ExecutionMode.SEQUENTIAL:
                results = await self._execute_sequential(wave)
            elif mode == ExecutionMode.PARALLEL:
                results = await self._execute_parallel(wave)
            elif mode == ExecutionMode.WAVE:
                results = await self._execute_wave(wave)
            elif mode == ExecutionMode.CONDITIONAL:
                results = await self._execute_conditional(wave)
            elif mode == ExecutionMode.HITL:
                results = await self._execute_hitl(wave)
            
            # 质量门禁检查
            if not self._pass_quality_gate(wave, results):
                print(f"❌ Wave {wave_idx + 1} failed quality gate")
                await self._handle_wave_failure(wave, results)
                return False
            
            # 更新任务状态
            for result in results:
                self.state["tasks"][result.task_id] = {
                    "status": "COMPLETED" if not result.error else "FAILED",
                    "agent": result.agent_id,
                    "outputs": result.outputs,
                    "completed_at": datetime.utcnow().isoformat()
                }
            self._save_state()
        
        self.state["status"] = "COMPLETED"
        self._save_state()
        return True
    
    async def _execute_parallel(self, tasks: List[Task]) -> List[DispatchResult]:
        """并行执行 wave 内所有任务"""
        coroutines = [self._dispatch(task) for task in tasks]
        results = await asyncio.gather(*coroutines, return_exceptions=True)
        
        # 处理异常
        processed = []
        for r in results:
            if isinstance(r, Exception):
                processed.append(DispatchResult(
                    task_id="unknown",
                    agent_id="unknown",
                    status="FAILED",
                    outputs=[],
                    error=str(r)
                ))
            else:
                processed.append(r)
        return processed
    
    async def _dispatch(self, task: Task) -> DispatchResult:
        """分派单个任务给 Agent"""
        start_time = time.time()
        try:
            # 通过 OpenClaw sessions_send 调用 Agent
            response = await self.orchestrator.call_agent(
                agent_id=task.agent,
                message={
                    "type": "TASK_ASSIGN",
                    "task_id": task.id,
                    "task_description": task.description,
                    "inputs": task.inputs,
                    "expected_outputs": task.outputs,
                }
            )
            
            return DispatchResult(
                task_id=task.id,
                agent_id=task.agent,
                status="COMPLETED" if response.success else "FAILED",
                outputs=response.outputs,
                duration_seconds=time.time() - start_time,
                error=response.error if not response.success else None
            )
        except Exception as e:
            return DispatchResult(
                task_id=task.id,
                agent_id=task.agent,
                status="FAILED",
                outputs=[],
                duration_seconds=time.time() - start_time,
                error=str(e)
            )
    
    def _pass_quality_gate(self, wave: List[Task], results: List[DispatchResult]) -> bool:
        """检查 wave 是否通过质量门禁"""
        for task, result in zip(wave, results):
            gate = self.quality_gates.get(task.id)
            if gate and not gate.check(result):
                return False
        return True
    
    async def _handle_wave_failure(self, wave: List[Task], results: List[DispatchResult]):
        """处理 wave 失败：回溯修复"""
        for task, result in zip(wave, results):
            if result.status == "FAILED":
                task.retry_count += 1
                
                if task.retry_count > task.max_retries:
                    # 升级人工
                    await self._escalate_to_human(task, result)
                else:
                    # 回溯到上游 Agent
                    await self._reassign_task(task, result)
```

## 五、调度决策的"业务规则"

### 规则 1：HITL 强制点

以下节点**必须**人工审批：
- PRD 完成后（开始 UI/架构前）。
- 架构评审完成后（开始编码前）。
- 测试通过后（部署前）。
- 任何修改核心契约的请求。

### 规则 2：失败重试预算

- 单任务最多重试 3 次。
- wave 内任意任务失败 → wave 失败。
- wave 失败超过 2 次 → 升级人工。

### 规则 3：资源限制

- 同时运行的 Agent 数量 ≤ 5（避免 Token 成本爆炸 + 监控复杂度）。
- 单 wave 内任务数 ≤ 5（避免资源抢占）。
- 单任务执行时间 ≤ 30 分钟（超过视为 Agent 卡死，强制中断）。

### 规则 4：超时与降级

- 单任务执行超过 30 分钟 → 中断 + 重试。
- Agent 调用失败率 > 20% → 降级到基础模型 + 减少并发。

## 六、Lobster DSL 工作流示例

完整电商小程序工作流：

```yaml
# lobsters/ecommerce_project.yaml
name: "E-commerce Mini Program"
mode: wave

variables:
  project_name: "ecommerce-miniapp"
  approver: "user"

waves:
  - wave: 1
    mode: sequential
    tasks:
      - id: "T1.1"
        agent: "product"
        task: "Write PRD"
        inputs: ["{{ user_requirement }}"]
        outputs: ["shared/01_PRD/PRD.md"]

  - wave: 2
    mode: hitl
    steps:
      - id: "T2.0"
        action: "pause_for_approval"
        artifact: "shared/01_PRD/PRD.md"
        approvers: ["{{ approver }}"]
      - id: "T2.1"
        agent: "ui_designer"
        task: "Define Design System"
        inputs: ["shared/01_PRD/PRD.md"]
        outputs: ["shared/02_UI/DesignSystem.md"]
      - id: "T3.1"
        agent: "architect"
        task: "Design System Architecture"
        inputs: ["shared/01_PRD/PRD.md"]
        outputs: ["shared/03_Arch/Architecture.md"]
        mode: parallel_with: "T2.1"

  - wave: 3
    mode: parallel
    tasks:
      - id: "T2.2"
        agent: "ui_designer"
        task: "Design Home Page"
        inputs: ["shared/02_UI/DesignSystem.md"]
        outputs: ["shared/02_UI/Wireframes/HomePage.md"]
      - id: "T2.3"
        agent: "ui_designer"
        task: "Design Product Detail Page"
        inputs: ["shared/02_UI/DesignSystem.md"]
        outputs: ["shared/02_UI/Wireframes/ProductDetail.md"]
      - id: "T2.4"
        agent: "ui_designer"
        task: "Design Cart & Checkout"
        inputs: ["shared/02_UI/DesignSystem.md"]
        outputs: ["shared/02_UI/Wireframes/CartCheckout.md"]
      - id: "T3.2"
        agent: "architect"
        task: "Design API Spec"
        inputs: ["shared/03_Arch/Architecture.md"]
        outputs: ["shared/03_Arch/APISpec.yaml"]

  - wave: 4
    mode: parallel
    tasks:
      - id: "T4.1"
        agent: "coder_backend"
        task: "Implement Backend"
        inputs: ["shared/03_Arch/APISpec.yaml"]
        outputs: ["/backend/"]
      - id: "T4.2"
        agent: "coder_frontend"
        task: "Implement Frontend"
        inputs:
          - "shared/02_UI/Wireframes/*"
          - "shared/03_Arch/APISpec.yaml"
        outputs: ["/frontend/"]

  - wave: 5
    mode: conditional
    branches:
      - condition: "tests_passed == true"
        then:
          - id: "T6.1"
            agent: "devops"
            task: "Deploy"
            inputs: ["/backend/", "/frontend/"]
            outputs: ["DeploymentGuide.md"]
      - condition: "tests_passed == false"
        then:
          - id: "T5.3"
            agent: "coder_backend"
            task: "Fix Bugs"
            loop_until: "tests_passed == true"
            max_iterations: 3
          - if_loop_fails:
              - action: "escalate_to_human"

error_handling:
  on_agent_timeout:
    action: "retry_with_different_model"
    max_retries: 2
  on_quality_gate_failure:
    action: "reassign_to_owner_agent"
    max_retries: 3
  on_unrecoverable_error:
    action: "escalate_to_human"
    notify: ["{{ approver }}"]
```

## 七、本章关键 takeaway

- 5 种执行模式：串行、并行、波次、条件、人工审批。
- 调度器根据任务特征自动选择模式。
- 状态机：IDLE → PLANNING → EXECUTING → 门禁 → 下一 wave。
- 业务规则：HITL 强制点、失败重试预算、资源限制、超时降级。
- Lobster DSL 把调度流程写成可执行 YAML。
