# 10 - 我对 AGI 路径的判断

> **TL;DR**：AGI 不会一蹴而就，但**垂直场景的"局部 AGI"会先到**。先重写的是客服、销售、内容生产、初级编码、初级法务、初级医疗辅助。

---

## 一、为什么我不预测 AGI 时间表

每隔一段时间就有声音说"AGI 还有 X 年"或"AGI 已经来了"。

我**拒绝**做这种时间表预测，因为：

- "AGI" 没有公认的定义。有人说"通过图灵测试"，有人说"完成 80% 知识工作"，有人说"具备自主目标设定能力"。每个定义的实现时间表完全不同。
- 历史教训：AI 领域的"X 年实现"预测，几乎全部失败。80 年代专家系统时代就有人预测"10 年内 AGI"，结果冬天来了。
- 真正的进步是非线性的，可能在某次技术突破（Transformer 级别）后突然加速。

所以我**不做时间表预测**，但**做路径推演**。

---

## 二、AGI 不会"突然到来"，但会"局部涌现"

这是我对 AGI 路径的核心判断：

> **AGI 不是从某个临界点突然"觉醒"的，而是在多个垂直场景中先达到"超人类表现"，再逐步连接、整合、涌现。**

我用"局部 AGI"这个概念：

> **局部 AGI = 在某个垂直场景下，AI 的表现持续、稳定、规模化地超过人类专家平均水平。**

判断标准（三个都要满足）：
1. **能力维度**：在该场景的关键能力指标上超过 95% 的人类从业者。
2. **稳定性**：7×24 在线，错误率低于人类平均错误率。
3. **规模化**：单位边际成本低于人类单位成本。

满足这三个标准，就是"局部 AGI"。

---

## 三、哪些场景会先达到"局部 AGI"？

按我自己的判断（信心指数：中），这些场景会先到：

### 高信心（已经在接近）
- **客服 / 一线支持**：AI 已经在处理 70%+ 标准化问题，剩下 30% 是复杂问题，2-3 年内会变成 95%。
- **初级编程**：GitHub Copilot / Cursor / Devin 已经覆盖大部分"模式化"编码任务。
- **内容初稿生成**：营销文案、新闻摘要、报告初稿，AI 已经能完成 80%。

### 中信心（5 年内可能到）
- **销售线索跟进**：自动外联、邮件回复、会议预约。
- **翻译 / 本地化**：高质量、低成本、实时。
- **初级法律文书**：合同审查、合规检查、文书起草。
- **初级医疗辅助**：影像识别、病历摘要、初步诊断建议（不是诊断本身）。

### 低信心（需要更多技术突破）
- **复杂谈判 / 战略决策**：需要多目标权衡、长链路推理。
- **0 到 1 的科学研究**：需要"灵感"和"试错"。
- **高水平创意写作**：需要"风格"和"读者共鸣"的人类判断。
- **跨领域迁移**：在 A 领域学到的不能直接迁移到 B 领域。

## 四、AGI 路径的 4 个关键技术

### 技术 1：Memory（长期记忆）

**现状**：当前 LLM 是"无状态"的，每次对话都是新开始。
**突破方向**：跨会话、跨用户、跨场景的持久化记忆。Memory Bank、向量数据库、知识图谱融合。
**判断**：未来 2-3 年的关键技术，谁先解决 Memory 谁就掌握下一代 Agent 的入口。

### 技术 2：Tool-use（工具使用）

**现状**：当前 Agent 已经能用工具（Function Calling），但工具调度不灵活。
**突破方向**：动态发现工具、组合工具、并行调用工具、错误恢复。
**判断**：MCP（Model Context Protocol）等标准会逐步统一工具生态，2 年内会成为"基础设施"。

### 技术 3：Multi-Agent（多 Agent 协作）

**现状**：OpenClaw、AutoGen、LangGraph 等框架已经能跑多 Agent 协作，但工程化挑战大。
**突破方向**：通信协议标准化、契约自动校验、调试可视化、协作质量评估。
**判断**：3-5 年内多 Agent 会成为"复杂任务"的标准解法。

### 技术 4：Self-improvement（自我改进）

**现状**：当前 Agent 不会从错误中学习。
**突破方向**：错误分析、prompt 自调优、模型自蒸馏、工具自生成。
**判断**：这是 AGI 的"圣杯"——如果 Agent 能自己改进自己，能力增长曲线会指数化。当前还很早期，5-10 年内可能有突破。

## 五、对个人和团队的影响

### 对个人
- **不要押注单一技能**。如果你的工作只是"模式化"（如基础编码、基础文书），会被局部 AGI 取代。
- **押注"AI + 领域"的复合能力**。领域理解 + AI 工具使用 > 纯领域能力 或 纯 AI 能力。
- **保持学习**。AGI 不是一蹴而就，**你有时间转型**。

### 对团队
- **重构组织结构**。"中层管理"角色会被 Agent 挤压，"Agent Operations"角色会出现。
- **重新设计岗位**。以前是"招聘一个专员"，未来可能是"招聘一个 Agent 训练师 + 一个 Agent 监督员"。
- **投资 AI 基础设施**。数据飞轮、监控体系、Agent 工具链，3 年内是必投项。

---

## 六、我自己的 AGI 信仰与怀疑

### 信仰
- **垂直场景的局部 AGI 一定会来**，而且会持续到来。
- **多 Agent 协作会解锁大量新的应用场景**。
- **AI 工具的普及会让"会用 AI"成为基础素养**。

### 怀疑
- **通用 AGI 的时间表不可预测**。我怀疑有人能可靠预测。
- **"AGI 觉醒"这种叙事更像科幻**。更可能的是"渐进涌现"。
- **AGI 不等于"取代人类"**。更可能是"重新定义人类角色"。

---

## 七、本文小结

- 不预测 AGI 时间表，做路径推演。
- AGI 不会突然到来，会在垂直场景中"局部涌现"。
- 高信心场景：客服、初级编程、内容生成。
- 中信心场景：销售、翻译、初级法律和医疗。
- 关键技术：Memory、Tool-use、Multi-Agent、Self-improvement。
- 对个人：押注"AI + 领域"复合能力。
- 对团队：重构组织、重新设计岗位、投资基础设施。
