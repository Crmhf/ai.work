## 写作风格

- 每篇 800~2000 字。
- 有观点、有案例、有判断。**不写"仁者见仁智者见智"式的废话**。
- 案例尽量来自我自己真实的工作场景，或者公开发布的产品/论文。
- 不引用未经验证的传闻，对 AI 行业的"神话"保持警惕。
