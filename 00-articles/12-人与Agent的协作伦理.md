# 12 - 人与 Agent 的协作伦理

> **TL;DR**：Agent 协作的伦理不是抽象哲学，是**具体的工程决策**——责任归属、信任校准、能力边界、隐私保护、人类能动性。

---

## 一、为什么 Agent 时代需要重新谈伦理

AI 时代谈伦理不新鲜，但 **Agent 时代谈伦理有新的具体问题**：

- 以前的 AI 是"工具"，出错怪使用者。Agent 是"自主体"，出错归谁？
- 以前的 AI 没有"记忆"，隐私问题小。Agent 长期记忆用户数据，隐私边界在哪？
- 以前的 AI 没有"目标"，不会主动做事。Agent 自己组织工作，如何避免它"越权"？
- 以前的 AI 没有"说服力"，人类保持清醒。Agent 太有说服力，人类可能被"操控"。

这不是哲学问题，是**每天设计 Agent 产品时要做的决策**。

---

## 二、5 个核心伦理决策

### 决策 1：责任归属（Who is responsible）

**问题**：Agent 做出了错误决策（如订错机票、转错账），谁负责？

**三种立场**：
- **使用者全责**：Agent 是工具，使用者应该审查。→ 大多数法律系统的默认立场。
- **Agent 厂商共担**：Agent 不是普通工具，厂商有义务提供合理保护。→ 欧盟 AI 法案倾向。
- **Agent 自主担责**：Agent 有自主决策能力，应承担独立责任。→ 当前法律不支持。

**我的判断**：当前阶段**使用者主责 + 厂商协助**。

- Agent 必须给出**清晰可追溯的决策日志**（不是黑盒）。
- 关键操作（高金额、高风险）必须**人类审批**。
- Agent 厂商必须提供**风险预警 + 撤销机制**。

### 决策 2：信任校准（Trust calibration）

**问题**：用户对 Agent 的信任应该多深？

**三种典型失败**：
- **过度信任**：用户全盘接受 Agent 输出，不审查。结果：Agent 出错时损失巨大。
- **不足信任**：用户完全不信任 Agent，事事自己来。结果：Agent 没有价值。
- **错位信任**：用户信任 Agent 做对的事（如精确计算），但不信任 Agent 做错的事（如创作判断）。

**我的判断**：建立**渐进式信任**机制。

- 首次使用：必须审查每个 Agent 输出。
- 使用稳定后：根据"成功率"和"用户反馈"动态调整信任等级。
- 高风险操作：永远要求人类审批。

技术上：**让 Agent 显示"信心指数"**，人类基于信心指数做决策。

### 决策 3：能力边界（Capability boundary）

**问题**：Agent 应该在什么范围内自主行动？

**三种立场**：
- **无限制**：Agent 能做就让它做，相信 AI。→ 风险极大。
- **全限制**：Agent 什么都必须问人类。→ 失去 Agent 价值。
- **分级限制**：低风险自动、中风险预览、高风险审批。

**我的判断**：**分级限制 + 显式契约**。

- 每个 Agent 都有明确的"能力清单"（能做什么、不能做什么）。
- 能力清单之外的动作必须人类审批。
- 能力清单可以动态调整，但要可追溯。

### 决策 4：隐私保护（Privacy）

**问题**：Agent 长期记忆用户数据，隐私怎么保护？

**三个原则**：
- **数据最小化**：Agent 只记忆必要的数据，不多记。
- **用户可控**：用户可以查看、编辑、删除 Agent 的记忆。
- **目的限制**：Agent 记忆的数据只能用于授权的目的，不能用于"训练下一代 Agent"（除非用户明确同意）。

**我的判断**：**用户对记忆有完全控制权**。

- Agent 不能"偷偷"记住什么。
- 用户可以随时"忘记我"（清空所有记忆）。
- Agent 厂商不能把用户记忆卖给第三方。
- 跨用户共享的记忆必须匿名化 + 聚合化。

### 决策 5：人类能动性（Human agency）

**问题**：Agent 越来越能干，人类会不会"被惯坏"？

**三种风险**：
- **能力退化**：人类长期依赖 Agent，自己的能力会下降（如不写代码后不会写代码）。
- **决策疲劳**：人类审批 Agent 的所有关键决策，久而久之变得"机械式同意"。
- **认知外包**：人类把思考外包给 Agent，失去独立判断能力。

**我的判断**：**刻意保留人类的"动手能力"**。

- 关键决策必须人类深度参与，不只是"点同意"。
- 周期性"无 Agent 工作日"，让人类保持基本能力。
- 教育下一代时，必须教"不用 Agent 也能做"的能力。
- Agent 不能"代替人类做价值判断"（如道德、艺术、政治）。

## 三、我的 8 条伦理原则

作为每天设计 Agent 产品的实践者，我给自己定 8 条原则：

1. **Agent 必须可解释**：每个决策都有 trace，trace 可被人类审查。
2. **关键操作必须人类审批**：高风险操作（金额、删除、外部通信）必须人类点头。
3. **失败必须可恢复**：Agent 的每个写入操作都可回滚。
4. **记忆必须用户可控**：用户能查看、编辑、删除 Agent 的所有记忆。
5. **能力必须显式**：每个 Agent 的能力清单、限制清单是文档化的。
6. **信任必须渐进**：根据成功率、用户反馈动态调整信任等级。
7. **人类能动性必须保留**：不让 Agent 完全替代人类的思考与决策。
8. **失败必须诚实**：Agent 出错时不掩饰、不甩锅，主动告知并提供修复方案。

---

## 四、给 Agent 设计者的清单

如果你正在设计 Agent 产品，按这个清单自检：

- [ ] Agent 的每个决策都有 trace，日志可被用户审查。
- [ ] 高风险操作有"必须人类审批"机制。
- [ ] Agent 的所有写入操作都可回滚。
- [ ] 用户能查看、编辑、删除 Agent 记忆。
- [ ] Agent 的能力清单和限制清单文档化。
- [ ] Agent 显示"信心指数"，帮助人类决策。
- [ ] Agent 失败时主动告知并提供修复方案。
- [ ] Agent 不代替人类做价值判断。

---

## 五、伦理不是"道德高地"，是"产品差异化"

有人觉得伦理是"道德高地"，是公关话题。**我反对**。

在 Agent 时代，**伦理设计直接是产品竞争力**：

- 可解释 → 用户敢用。
- 可恢复 → 用户不怕出错。
- 可控记忆 → 用户愿意授权数据。
- 显式能力 → 用户知道边界。
- 渐进信任 → 用户不会"全盘接受 / 全盘拒绝"。

一个**不重视伦理的 Agent 产品**，会变成"看起来 AI 很强，实际用户不敢用"的产品。

---

## 六、本文小结

- 5 个核心伦理决策：责任归属、信任校准、能力边界、隐私保护、人类能动性。
- 我的 8 条原则：可解释、关键审批、可恢复、记忆可控、能力显式、信任渐进、人类能动、失败诚实。
- 伦理设计是产品竞争力，不是道德高地。
- 8 项自检清单，每个 Agent 产品都该过一遍。
