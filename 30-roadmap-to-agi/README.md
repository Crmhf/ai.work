## 立场声明

- **不做"AGI 何时到来"的赌博式预测**。这种预测既不可证伪也不可验证。
- **承认"局部 AGI"先于"通用 AGI"到来**。垂直场景的"超人类表现"会先出现。
- **警惕"Agent 万能论"和"Agent 无用论"两种极端**。
- **保持每周/每两周更新一次**，因为这个领域变化太快。
