# 08 - AI 创业者的机会地图

> **TL;DR**：AI 时代有 4 类创业机会——**垂直 Agent、Agent 工具、Agent 平台、Agent 内容**。本篇给出每类的具体机会和风险评估。

---

## 一、4 类创业机会

### 类别 1：垂直 Agent（最大机会）

#### 定义

专注特定垂直场景的 Agent 产品（法律、医疗、销售、教育等）。

#### 代表

- Harvey（法律）
- Clay（销售）
- Hebbia（金融）
- Hippocratic AI（医疗）
- Speak（语言学习）

#### 为什么是最大机会

- **市场大**：垂直行业每个都是千亿市场。
- **护城河深**：行业知识 + 数据 + 客户关系。
- **能盈利**：垂直场景 ROI 清晰，客户愿意付费。

#### 风险

- **行业进入门槛**：需要行业 know-how。
- **数据获取**：垂直数据往往在企业内部。
- **合规风险**：医疗、金融等强合规场景。

#### 我的判断

> **垂直 Agent 是 AI 创业的最佳赛道**。未来 5 年会出现 100+ 家垂直 Agent 公司。

---

### 类别 2：Agent 工具（中等机会）

#### 定义

做 Agent 开发工具、平台、基础设施。

#### 代表

- LangChain（Agent 框架）
- LangGraph（图编排）
- LangSmith（可观测性）
- Pinecone（向量数据库）
- Composio（MCP 工具集成）

#### 为什么是中等机会

- **开发者市场**：全球开发者市场大。
- **标准化机会**：MCP 等协议正在标准化。
- **可复利**：一次开发，多次复用。

#### 风险

- **大厂入场**：大厂（OpenAI、Anthropic）可能自建工具。
- **开源压力**：开源生态可能压缩商业空间。
- **同质化**：工具类容易同质化。

#### 我的判断

> **Agent 工具是有机会，但窗口期在缩短**。2-3 年内大厂会入场，要快速建立壁垒。

---

### 类别 3：Agent 平台（中等机会）

#### 定义

Agent 应用市场、Agent 集成平台、Agent-as-a-Service。

#### 代表

- Replit（Agent + IDE）
- Cursor（Agent IDE）
- Adept（Computer Use Agent）
- Sierra（客服 Agent 平台）

#### 为什么是中等机会

- **网络效应**：用户越多，平台越有价值。
- **数据飞轮**：用户行为数据可优化 Agent。

#### 风险

- **大厂挤压**：大平台（OpenAI、Anthropic、Microsoft）有天然优势。
- **冷启动难**：平台需要双边用户。

---

### 类别 4：Agent 内容（新兴机会）

#### 定义

用 Agent 生成内容（视频、音乐、写作、设计）。

#### 代表

- Suno（AI 音乐）
- Midjourney（AI 图像）
- Runway（AI 视频）
- Jasper（AI 写作）

#### 为什么是新兴机会

- **内容需求大**：永远有内容需求。
- **Agent 提效 10x+**：Agent 比人工便宜得多。
- **新形态**：AI 原生内容（小说、视频）可能有全新市场。

#### 风险

- **版权问题**：AI 生成内容的版权仍不明确。
- **质量不稳定**：高质量内容仍需人工 review。
- **同质化**：内容工具容易被复制。

---

## 二、垂直 Agent 机会地图

### 高机会（垂直大 + 数据可得 + 客户付费意愿）

#### 1. 法律 AI

- **场景**：合同审查、法律研究、文档自动化。
- **市场规模**：$1T+（全球法律服务）。
- **代表**：Harvey（估值 $1.5B+）。
- **机会**：中国法律 AI 市场才起步。
- **进入门槛**：需要律师合作、行业 know-how。

#### 2. 销售 AI

- **场景**：线索挖掘、外联、客户跟进、会议预约。
- **市场规模**：$500B+（全球销售工具）。
- **代表**：Clay（估值 $500M+）、11x.ai。
- **机会**：B2B 销售在中国是 100 万+企业的痛点。

#### 3. 客服 AI

- **场景**：一线问题处理、邮件回复、工单分流。
- **市场规模**：$500B+（全球客服）。
- **代表**：Sierra、Decagon、Intercom Fin。
- **机会**：中国客服 AI 需求大（劳动密集）。

#### 4. 营销 AI

- **场景**：内容生成、邮件营销、社媒运营。
- **市场规模**：$300B+（全球营销工具）。
- **代表**：Jasper、Persado。
- **机会**：营销内容是中国中小企业刚需。

#### 5. 教育 AI

- **场景**：个性化辅导、出题、批改、口语练习。
- **市场规模**：$300B+（全球教育）。
- **代表**：Speak、Speakly、Quizlet Q-Chat。
- **机会**：中国教育市场大，家长付费意愿强。

#### 6. 医疗 AI

- **场景**：影像识别、病历摘要、辅助诊断。
- **市场规模**：$500B+（全球医疗 IT）。
- **代表**：Hippocratic AI、Glass Health。
- **机会**：中国基层医疗需求大（医生短缺）。
- **风险**：强合规、强监管。

#### 7. 金融 AI

- **场景**：风险评估、投资研究、报告生成。
- **市场规模**：$300B+（全球金融 IT）。
- **代表**：Hebbia、Rogo。
- **机会**：中国金融科技有空间。
- **风险**：强合规、监管严格。

---

### 中等机会（垂直中等 + 付费意愿中等）

#### 8. 招聘 AI

- **场景**：简历筛选、面试安排、人才匹配。
- **市场规模**：$200B+（全球招聘）。
- **代表**：Mercor、Eightfold。

#### 9. 数据分析 AI

- **场景**：自动 SQL 生成、报表生成、数据洞察。
- **市场规模**：$200B+（全球 BI）。
- **代表**：ChatBI、Defog。

#### 10. 设计 AI

- **场景**：UI 生成、海报设计、Logo 生成。
- **市场规模**：$100B+（全球设计工具）。
- **代表**：Galileo AI、Recraft。

---

### 低机会（垂直小 / 客户付费意愿低）

- **写作 AI**（已被 Notion AI / ChatGPT 占领）。
- **翻译 AI**（已被 DeepL / Google 占领）。
- **代码助手**（已被 Cursor / Copilot 占领）。

---

## 三、Agent 工具机会地图

### 已有巨头（高门槛）

- **LangChain**：Agent 框架领头羊。
- **LangGraph**：图编排。
- **Pinecone / Weaviate**：向量数据库。
- **Anthropic MCP**：协议标准。

### 仍有空间（细分）

#### 1. Agent 可观测性

- **现状**：LangSmith（LangChain 官方）、Langfuse（开源）。
- **机会**：企业级 Agent 可观测性平台。
- **进入方式**：与 LangChain 兼容 + 企业特性。

#### 2. Agent 评测平台

- **现状**：缺少专业 Agent 评测平台。
- **机会**：评测 + 报告 + benchmark。
- **进入方式**：与主流框架集成。

#### 3. Agent 工具市场

- **现状**：Composio 已起步。
- **机会**：MCP Server 市场。
- **进入方式**：聚集 MCP 开发者。

#### 4. Prompt 工程平台

- **现状**：PromptLayer、Agenta。
- **机会**：企业级 prompt 管理 + A/B 测试。
- **进入方式**：集成 LLM 厂商。

## 四、创业执行路径

### 阶段 1：想法验证（0-3 个月）

```
- 选垂直场景（高频、刚需、ROI 清晰）
- 找 5-10 个目标用户访谈
- 验证 PMF（用户愿意付费）
- 跑通 MVP（手动 + AI 辅助）
```

**关键**：**不要写代码**，先验证 PMF。

### 阶段 2：MVP 启动（3-6 个月）

```
- 2-5 人小团队
- 核心 AI 能力
- 10-20 个付费客户
- 收入 $5K-$30K MRR
```

**关键**：**最快速度跑通**。

### 阶段 3：PMF 确认（6-12 个月）

```
- 扩大团队到 10-20 人
- 数据飞轮启动
- 50-100 个付费客户
- 收入 $50K-$300K MRR
```

**关键**：**建立数据飞轮 + 工程化**。

### 阶段 4：规模化（12-24 个月）

```
- 团队到 30-50 人
- 多场景扩展
- 500+ 付费客户
- 收入 $300K-$1M MRR
```

**关键**：**横向扩展 + 销售能力**。

### 阶段 5：行业领先（24-36 个月）

```
- 行业第一 / 第二
- 准备下一轮融资或 IPO
```

## 五、避坑指南

### 坑 1：选错垂直

- **症状**：选了 ROI 不清晰的场景（如"通用写作"）。
- **解决**：选**高频 + 刚需 + ROI 清晰**。

### 坑 2：PMF 没验证就扩张

- **症状**：融资后快速扩张。
- **解决**：**小团队验证 PMF 再扩张**。

### 坑 3：与 ChatGPT 直接竞争

- **症状**：做"中国版 ChatGPT"。
- **解决**：**垂直场景 + 差异化**。

### 坑 4：忽视合规

- **症状**：医疗、法律 AI 不重视合规。
- **解决**：**专业律师 + 合规设计**。

### 坑 5：盲目烧钱

- **症状**：没有清晰的盈利路径。
- **解决**：**18 个月内能盈利**。

---

## 六、本章关键 takeaway

- **4 类 AI 创业机会**：垂直 Agent、Agent 工具、Agent 平台、Agent 内容。
- **最大机会**：垂直 Agent（市场大、护城河深、能盈利）。
- **7 个高机会垂直**：法律、销售、客服、营销、教育、医疗、金融。
- **创业路径**：PMF 验证 → MVP → PMF 确认 → 规模化 → 行业领先。
- **避坑**：选对垂直、验证 PMF 再扩张、不与 ChatGPT 竞争、重视合规、不盲目烧钱。
