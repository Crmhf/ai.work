# 60-faq — FAQ / 速查

> 工作中遇到的具体问题、踩过的坑、最常被问的疑问，**整理成 FAQ**。
> 形式：问题 → 简明答案 → 详细解释（可选）→ 相关文档链接。

- **02** [多 Agent 编排 FAQ](./02-多Agent编排FAQ.md) — OpenClaw / 多 Agent 的实战问题

- **05** [成本与限流 FAQ](./05-成本与限流FAQ.md) — LLM 成本控制 / API 限流应对

---

## 风格

- **简明**：每个问题 1-3 句回答。
- **可执行**：能直接 copy 代码或配置。
- **关联**：链接到更详细的文档。

---

## 适用场景

- 工作中遇到具体问题，**先来 FAQ 查**。
- 找不到答案再去深度文档找。
- FAQ 是"快速入口"，深度文档是"完整参考"。
